# e-commerce-copy-Ralph-Lauren-## 
This project was developed using a custom MVC architecture in pure PHP. 
The application integrates session management, API communication, and a MySQL database managed through phpMyAdmin.

The platform is an e-commerce web application for clothing products. 
It includes a fully functional product catalog displayed on the homepage, along with a dedicated product details page for each item. 
Every product has dynamic stock management based on selected size and color variations.

The application also features a complete shopping cart system with checkout functionality. 
During the checkout process, users can apply promo codes, and the total price is automatically recalculated depending on the discount value.

Additionally, the project includes an order success page displayed after a successful purchase.

### Main Features
- Custom MVC architecture in PHP
- Session management
- API integration
- MySQL database with phpMyAdmin
- Product catalog and product details pages
- Dynamic stock handling based on size and color
- Shopping cart functionality
- Checkout system
- Promo code support with dynamic price updates
- Order success page
